# Сайт AKM Studios

Одностраничный сайт студии: загрузка-«лента истории кино», шоурил внутри логотипа, семь сцен «Сделано AKM Studios», метод работы, услуги, цифры, форма заявки.

## Что внутри

| Файл | Зачем |
|---|---|
| `index.html` | разметка и все тексты сайта |
| `css/styles.css` | оформление: цвета, шрифты, адаптив |
| `js/main.js` | анимации, видео, форма; **вверху — настройки контактов** |
| `media/` | видео (без звука), логотипы, превью для соцсетей |
| `robots.txt` | разрешает индексацию |

Отдельно рядом лежит `AKM_Studios.html` — тот же сайт одним файлом (стили, скрипт и видео внутри). Его можно открыть двойным кликом или отправить в мессенджере. Для хостинга используйте папку `dist/`: там видео в полном качестве и страница грузится быстрее.

## Перед запуском заполнить

Откройте `js/main.js`, блок `AKM_CONFIG` в самом начале:

```js
const AKM_CONFIG = {
  telegram: 'https://t.me/...',
  vk: 'https://vk.com/...',
  mail: 'mailto:...',
  youtube: 'https://youtube.com/@...',
  formEndpoint: '',   // куда отправлять заявку
};
```

- Пустая ссылка на сайте не кликается — так видно, что не заполнено.
- **Форма заявки.** Пока `formEndpoint` пустой, форма только показывает «Спасибо». Чтобы заявки приходили на почту, подойдёт любой сервис приёма форм (например, Formspree, Getform) или свой обработчик: вставьте его адрес, форма отправит POST с полями `name`, `artist`, `contact`, `format`, `release` в JSON.

## Как опубликовать

Сайт статический, сервер не нужен. Подходит любой хостинг статики:

- **Netlify / Vercel** — перетащить папку `dist` в окно деплоя.
- **GitHub Pages** — загрузить содержимое `dist` в репозиторий, включить Pages.
- **Обычный хостинг** — залить содержимое `dist` в корень сайта по FTP.

После публикации добавьте в `index.html` полный адрес картинки для соцсетей, например `<meta property="og:image" content="https://ваш-домен/media/og.jpg">` — так превью ссылки будет работать в Telegram и VK.

## Как поменять

- **Тексты** — прямо в `index.html`, они идут сверху вниз в порядке блоков.
- **Цвета** — в начале `css/styles.css`, переменные `--bg`, `--text`, `--accent`.
- **Видео** — заменить файл в `media/` с тем же именем (MP4 H.264, без звука, до ~3 Мбит/с для лупов).

## Технически

- Шрифты Google Fonts (Cormorant Garamond, Manrope, JetBrains Mono), анимации GSAP 3.12.5 + ScrollTrigger, плавный скролл Lenis 1.1.13 — подключаются с CDN.
- Звука на сайте нет: у всех видео отсутствует аудиодорожка.
- Видео грузятся лениво и ставятся на паузу вне экрана; на телефоне шоурил 720p.
- Учитывается системная настройка «уменьшить движение»: анимации отключаются, контент остаётся.
- Проверено: Chrome на десктопе 1440×900, планшет 1024×768, телефон 375×812.
