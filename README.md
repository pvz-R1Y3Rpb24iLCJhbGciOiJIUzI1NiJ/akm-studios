# Сайт-визитка AKM Studios

Один экран. На старте ролик играет внутри букв «AKM Studios», от первого движения (или сам через 3 секунды) камера влетает в букву K и открывается визитка: главная фраза, ИИ-строка с параметрами текущего кадра, услуги и кнопки связи. Просматривается за 15–20 секунд.

## Что внутри

| Файл | Зачем |
|---|---|
| `index.html` | разметка и тексты |
| `css/styles.css` | оформление: цвета, шрифты, адаптив |
| `js/main.js` | ссылки на контакты (**настройки вверху файла**) и запуск видео |
| `media/` | фоновое видео (1080p и лёгкое 720p для телефонов), постер, логотип, картинка для соцсетей |

Рядом лежит `AKM_Studios.html` — тот же сайт одним файлом (видео внутри), его можно открыть двойным кликом или переслать.

## Перед запуском заполнить

`js/main.js`, блок `AKM_CONFIG`:

```js
const AKM_CONFIG = {
  instagram: 'https://www.instagram.com/akm__studios/',
  telegram: 'https://t.me/...',
  vk: 'https://vk.com/...',
  mail: 'mailto:...',
};
```

Сейчас работает Instagram. Почта (главная кнопка) и ВКонтакте — заглушки: кнопки видны, но не кликаются, пока не вписана ссылка. Telegram с пустой ссылкой не показывается.

## Как опубликовать

Сайт статический: подходит любой хостинг статики (GitHub Pages, Netlify, Vercel, обычный хостинг по FTP) — залить содержимое папки в корень. После публикации пропишите в `index.html` полный адрес картинки для соцсетей: `<meta property="og:image" content="https://ваш-домен/media/og.jpg">`.

## Технически

- Шрифты Google Fonts: Unbounded (заголовок), Onest (текст). Сторонних скриптов нет.
- Видео без звука, на телефонах грузится версия 720p, в фоновой вкладке ставится на паузу.
- Учитывается системная настройка «уменьшить движение»: видео не запускается, остаётся кадр-постер.

## Три версии сайта

| Версия | Адрес | Идея |
|---|---|---|
| **1** | `/` | Тёмная визитка на один экран: ролик внутри логотипа, пролёт в букву K, главная фраза, ИИ-строка с параметрами кадра, контакты. Просмотр за 15–20 секунд. |
| **2** | `/v2/` | Светлая журнальная подача (бумага, графит, киноварь; шрифт Geologica): заявление «Режиссура человека. Кадры нейросети.», шоурил в кинокадре 2.39:1, плёнка из 9 стоп-кадров, схема «Режиссёр ∩ Нейросеть = AKM Studios», процесс в 4 шага, контакты. |
| **3** | `/v3/` | Гибрид: интро «нейросеть обучается и за ~10 с собирает логотип из частиц» (эпохи, loss, точность), затем ролик внутри букв и пролёт → визитка версии 1 → блоки версии 2 в тёмном исполнении. |

Исходники — `versions/v1`, `versions/v2`, `versions/v3`. Сборка всех трёх: `python build.py` → `dist/` (+ `AKM_Studios_v1.html`, `_v2.html`, `_v3.html` — каждая версия одним файлом). В версии 3 для проверки интро можно открыть страницу с параметром `?nnt=6000` — интро начнётся с 6-й секунды.

## Исследование конкурентов (22.10.2026)

**Мир:** Secret Level (secretlevel.co), Asteria Film Co. (asteriafilm.com), Staircase Studios AI (staircasestudios.ai), Promise, Wonder Studios.
Общее у лидеров: минимум текста и одно сильное заявление; работы и шоурил в центре; тезис «человек ведёт историю, ИИ — инструмент» («Story first. Human always» у Staircase, «Hollywood craftsmanship at the speed of culture» у Secret Level); Asteria — светлая журнальная подача с круговой диаграммой.

**Россия:** SLOI AI (sloi.ai), Ruvision AI (ruvision.ru/ai), Mediabanda (mediabanda.ru), Agentura Studio (agentura.studio), Visual Dynamics (visual-dynamics.ru).
Общее: тёмные или корпоративные шаблоны, ленты логотипов клиентов, тарифы, FAQ, много однотипных кнопок; сильные стороны — понятный процесс по шагам и кейсы «задача → решение».

Вывод для версии 2: светлая журнальная подача уровня мировых студий (ни у кого из российских конкурентов её нет), работа в центре, тезис «человек + ИИ» как визуальная идея, понятный процесс из российской практики — без перегруза.
